SLS-1 v3 recognition research

This page is no longer a conformance gate.

SLS-1 v3 now models indicator use as:

notice → investigate → lookup → learned recognition

An unfamiliar user is not required to infer an exact state name from a light on first sight.

Why the quiz was retired

The blind single-light research run scored 17/21 (81.0%). A later complete-panel test shown for one second and hidden before answer scored 14/21 (66.7%).

The second harness had become a visual-search and short-term-memory task rather than a realistic test of persistent status indicators.

Both results remain useful negative evidence. Neither justifies adding more flash codes.

Current evidence model

Test real implementations for noticeability, successful lookup, correct understanding after lookup, and increasing familiarity through use. Keep the indicator visible while it is relevant.
